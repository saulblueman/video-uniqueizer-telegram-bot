# Бот Уникализатор Видео (Advanced Version)

#### Это улучшенная версия оригинального бота. Инструкция предназначена для систем на базе Linux (Ubuntu/Debian). Если вы используете Windows, принципы установки схожи, но пути и активация venv будут отличаться.

## Описание проекта

Этот бот — мощный инструмент для уникализации видеоконтента перед публикацией в социальных сетях (TikTok, Reels, Shorts). Он построен на базе библиотеки **[Telethon](https://docs.telethon.dev/en/stable/#)** и использует мультимедийный фреймворк **[FFmpeg](https://ffmpeg.org/)** для глубокой обработки видео.

В этой версии добавлен функционал **профессиональной настройки фильтров**, что позволяет изменять визуальный ряд видео индивидуально для каждого пользователя.

### Основные возможности:
*   **Изменение битрейта:** Оптимизация размера и качества файла.
*   **Отзеркаливание:** Горизонтальный флип изображения.
*   **Наложение изображения:** Добавление водяных знаков или статичных фильтров (.png).
*   **Очистка метаданных:** Полное удаление информации о создателе, устройстве и геолокации.

### 🎛 Новое: Настройки видеофильтров (FFmpeg)
Теперь через меню «Настройки видео» можно задать:
*   **Яркость и Контраст:** Точная настройка в процентах.
*   **Резкость (Sharpness):** Улучшение детализации видео.
*   **Шум (Noise):** Добавление легкого цифрового шума для обхода алгоритмов детекции дубликатов.
*   **Сетка (Drawgrid):** Наложение динамической сетки с выбором цвета, прозрачности и размера ячеек.
*   **Персонализация:** Все настройки сохраняются индивидуально для каждого `user_id` в файл `user_settings.json`.

## Установка на Linux (Ubuntu/Debian)

### Предварительные требования
Убедитесь, что в вашей системе установлен FFmpeg:
```bash
sudo apt update && sudo apt install ffmpeg -y
```

### Шаги по установке

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/saulblueman/video-uniqueizer-telegram-bot.git
    cd video-uniqueizer-telegram-bot
    ```

2.  **Создайте и активируйте виртуальное окружение:**
    ```bash
    python3 -m venv venv
    source venv/bin/activate
    ```

3.  **Установите зависимости:**
    Проект использует `opencv-python-headless` для работы на серверах без графической оболочки.
    ```bash
    pip install -r requirements.txt
    ```

4.  **Настройка API и Токена:**
    *   Получите `BOT_TOKEN` у **[@BotFather](https://t.me/botfather)**.
    *   Получите `API_ID` и `API_HASH` на сайте **[my.telegram.org](https://my.telegram.org/)**.
    *   Создайте файл `.env` в корневой папке:
    ```bash
    nano .env
    ```
    *   Вставьте туда свои данные:
    ```env
    API_ID=123456
    API_HASH=ваш_hash_строка
    BOT_TOKEN=ваш_токен_бота
    ```

5.  **Подготовка ресурсов:**
    Убедитесь, что в корне проекта лежит файл `best_offer.png` (он используется для функции наложения картинки).

6.  **Запуск бота:**
    ```bash
    python3 bot.py
    ```

## Технический стек
*   **Python 3.9+**
*   **Telethon:** Работа с Telegram API.
*   **FFmpeg:** Обработка видеопотока.
*   **OpenCV:** Анализ характеристик видео (FPS, битрейт).
*   **Python-Decouple:** Безопасное управление конфигурацией через `.env`.

## Развертывание в фоне (Systemd)
Для бесперебойной работы рекомендуется использовать системную службу. Пример файла `videobot.service`:
```ini
[Unit]
Description=Video Uniqueizer Bot
After=network.target

[Service]
WorkingDirectory=/path/to/your/bot
ExecStart=/path/to/your/bot/venv/bin/python bot.py
Restart=always

[Install]
WantedBy=multi-user.target
