# 🚀 Video Uniqueizer Bot (Ultimate Advanced Version)

#### Профессиональный инструмент для обхода алгоритмов детекции дубликатов (Shadowban Protection) в TikTok, Reels, Shorts и других социальных сетях.

Инструкция предназначена для систем на базе **Linux (Ubuntu/Debian)**. Бот построен на базе библиотеки **Telethon** и использует всю мощь **FFmpeg** для глубокой переработки видеопотока.

## 🌟 Что нового в Advanced версии?

В отличие от стандартных скриптов, этот бот реализует многоуровневую систему уникализации, которая воздействует как на метаданные, так и на визуальный/аудио ряд.

### 1. Основные режимы обработки:
*   **📉 Изменить битрейт:** Принудительная пересборка структуры файла с уменьшением веса.
*   **🪞 Отзеркалить:** Горизонтальный флип (один из лучших способов обхода алгоритмов).
*   **🖼 Наложить картинку:** Автоматическое наложение вашего логотипа или водяного знака (.png).
*   **🚀 Только фильтры:** Новый интеллектуальный режим. Применяет все настройки из меню без отзеркаливания, используя **CRF (Constant Rate Factor)** для сохранения идеального баланса между качеством и уникальностью.

### 2. 🎛 Настройки видеофильтров (Standart):
*   **Яркость и Контраст:** Точечное изменение цветовой гаммы.
*   **Резкость (Sharpness):** Повышение детализации для улучшения визуального восприятия.
*   **Шум (Noise):** Добавление микро-зернистости, полностью меняющей хэш каждого кадра.
*   **Сетка (Drawgrid):** Наложение динамической сетки с выбором цвета, прозрачности и размера ячеек.

### 3. 🚀 Уникализация+ (Advanced):
*   **🔍 Зум (Crop/Scale):** Обрезка краев видео на 1-10%. Удаляет скрытые технические метки по краям кадра.
*   **🔄 Поворот:** Микро-поворот на доли градуса. Сбивает алгоритмы сопоставления контуров.
*   **🏃 Скорость:** Изменение скорости видео и аудио (например, на 1.01х). Полностью меняет аудио-хэш и PTS-метки видео, оставаясь незаметным для глаза.

### 4. Техническая защита:
*   **Очистка метаданных:** Полное удаление заголовков EXIF, данных об устройстве, GPS и софте.
*   **Индивидуальное хранилище:** Все настройки сохраняются для каждого пользователя в `user_settings.json`.

## 🛠 Установка на Linux (Ubuntu/Debian)

### 1. Предварительные требования
Убедитесь, что установлен системный FFmpeg:
```bash
sudo apt update && sudo apt install ffmpeg python3-pip python3-venv -y
```

### 2. Шаги по установке
```bash
# Клонируйте репозиторий
git clone https://github.com/saulblueman/video-uniqueizer-telegram-bot.git
cd video-uniqueizer-telegram-bot

# Создайте и активируйте виртуальное окружение
python3 -m venv venv
source venv/bin/activate

# Установите зависимости
# Используется headless-версия OpenCV для работы на серверах без монитора
pip install -r requirements.txt
```

### 3. Настройка окружения
Создайте файл `.env` в корне проекта:
```bash
nano .env
```
Вставьте ваши данные:
```env
API_ID=12345678            # Получить на my.telegram.org
API_HASH=ваш_api_hash      # Получить на my.telegram.org
BOT_TOKEN=ваш_токен_бота   # Получить у @BotFather
```

### 4. Подготовка ресурсов
*   Положите файл **`best_offer.png`** в корень папки (он будет использоваться как логотип).
*   Файл `user_settings.json` будет создан автоматически при первом изменении настроек.

### 5. Запуск
```bash
python3 bot.py
```
